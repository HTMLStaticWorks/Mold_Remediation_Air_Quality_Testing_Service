AeroPure Mold Remediation & Air Quality Testing Template

A multi-page HTML5/CSS3/ES6+ website and login-gated client portal designed specifically for certified environmental health, mold inspection, and remediation agencies.

1. Quickstart & Installation

This project is zero-dependency static HTML/CSS/JS. No heavy node bundler is strictly required to browse the static site, although any standard HTTP server (like Python's built-in server or Live Server) is recommended for development:

# Run local server with Python 3:
python -m http.server 8000

# Or with Node.js (npx):
npx serve .

Open http://localhost:8000 in any modern browser.

4. 3D Tilt Cards Engine

Cards automatically track the cursor coordinates within a 1200px perspective space. In accordance with strict requirements:

  • Centered Alignment: Card icons, headings, and descriptions are center-aligned across all viewport sizes.
  • Micro-Animation: Includes an animated clean air ripple and pulsing shield check.
  • Touch Graceful Degradation: On touch devices, mouse tracking is disabled to prevent stuck hover states.

5. Client Portal & Dashboard System

The dashboard contains 8 modules accessible via tab navigation with realistic skeleton loading:

  1. Overview: Active job metrics, health score, and next inspection timer.
  2. Schedule Inspection: Booking calendar with date and time picker.
  3. Job Status Tracker: 6-stage visual pipeline with technician notes.
  4. Air Quality Reports: Table of downloadable lab tests with modal preview.
  5. Before & After Documentation: High-res photo gallery with moisture ratings.
  6. Invoices & Billing: Mock checkout modal with instant status flipping from "Due" to "Paid".
  7. Messages: Direct chat with Lead Certified Industrial Hygienist.
  8. Settings: SMS preferences and profile management.
